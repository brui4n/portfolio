# Carpeta para Imágenes Estáticas de Proyectos

Coloca aquí tus capturas y archivos `.png` o `.jpg` para que carguen directamente en la web sin necesidad de importar.

### ¿Cómo referenciarlas en el código o en `src/data/portfolioData.ts`?
Al estar dentro de la carpeta `public/images/projects/`, la ruta directa en la web es:
`/images/projects/nombre-de-tu-imagen.png`

### Ejemplos sugeridos para tus secciones:
1. **Pasantías:**
   - `/images/projects/constancia-ntt-data.png`
   - `/images/projects/constancia-chiru.png`

2. **Proyecto Integrador SUMAQ:**
   - `/images/projects/sumaq-dashboard.png`

3. **Proyecto Android Kotlin:**
   - `/images/projects/android-kotlin-app.png`

4. **Evidencias de Networking:**
   - `/images/projects/linkedin-red-250.png`
   - `/images/projects/feedback-mentor.png`

Cualquier imagen que coloques aquí se servirá inmediatamente en la web en vivo.
